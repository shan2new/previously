## Findings

**The immediate missing evidence is a real iPhone recording.** Apple's case-specific request calls for the latest OS, footage beginning with launch, ordinary use, registration, login and deletion, plus applicable public-content controls and paid access. Purpose/audience, setup, services, regional differences and applicable documentation must also be explained in Reply and Review Notes. The current reply is saved as an unsent draft; recording and sample-upload placeholders remain. [Apple submission](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [preserved request](/Users/shan2new/Projects/previously/docs/qa/2026-10-07/app-store/rejection-dom.txt), [saved-draft receipt](/Users/shan2new/Projects/previously/docs/qa/2026-10-07/app-store/response-draft-saved-receipt.json).

**Two clips are our evidence-handling choice.** The guide uses the existing disposable account for login/use/deletion before a new disposable registration, preserving its exact protected-user verification guard. Each clip begins with launch. No official single-take rule or guarantee of two-clip acceptance was found in the actual request or public reply documentation. Similarly, the guide's **3–5 minute** target is practical guidance. Describe the two identities and the verification pause honestly. [Recording guide](/Users/shan2new/Projects/previously/docs/release/2026-10-07/physical-device-recording-guide.md), [verifier instructions](/Users/shan2new/Projects/previously/docs/qa/2026-10-06/native-live/live-account-erasure-verification.md), [Apple reply documentation](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/).

**The capture workflow needs no new spend.** Use the phone's native Screen Recording, which has a **3-second** countdown and saves to Photos, then AirDrop to the existing Mac. Selective USB Photos import or wired QuickTime capture are alternatives. QuickTime exports MOV; it does not export MP4. The zero-new-spend conclusion is an inference from using these existing tools and hardware. [Apple recording instructions](https://support.apple.com/en-us/102653), [AirDrop](https://support.apple.com/guide/iphone/use-airdrop-to-send-items-iphcd8b9f0af/ios), [USB transfer](https://support.apple.com/en-us/120267), [QuickTime capture](https://support.apple.com/guide/quicktime-player/record-a-movie-qtp356b55534/mac), [QuickTime export](https://support.apple.com/guide/quicktime-player/export-movies-qtp20e395859/mac).

**Review Notes have a byte limit.** Apple's reference specifies **4,000 bytes**, while the Reply interface shows **4,000 characters**. Each current plaintext template measures **3,584 characters / 3,584 UTF-8 bytes**, including its final newline, leaving 416 in each respective unit. Recheck after inserting real URLs; non-ASCII text can consume multiple bytes. [Apple Notes reference](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/), [Reply reference](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/), [measured budget receipt](/Users/shan2new/Projects/previously/docs/qa/2026-10-07/app-store/review-template-budget-check.json).

**An appeal is inappropriate for this information request.** Apple expressly excludes requests for further information/documentation from the App Review Board appeal path. Its unresolved-submission workflow permits editing the affected item, adding it for review and resubmitting once the issue is addressed. Follow the actual available controls when the evidence is complete. [Apple appeal guidance](https://developer.apple.com/help/app-review/after-submitting-for-review/appeal-to-the-app-review-board), [unresolved-submission workflow](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/manage-a-submission-with-unresolved-issues).
