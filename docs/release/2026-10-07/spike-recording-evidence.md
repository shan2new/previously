## Key findings

1. **Use iPhone Screen Recording and AirDrop first.** Apple's documented path is Control Center → Record → **3-second countdown** → return to Home Screen → launch the app. Recordings are saved in **Photos**. Microphone narration is optional. This uses the existing phone/Mac without introducing a recorder subscription, cloud-storage plan or new capture service; the zero-new-spend conclusion follows from choosing existing native tools. [Apple Screen Recording, published 14 September 2026](https://support.apple.com/en-us/102653), [Apple AirDrop](https://support.apple.com/guide/iphone/use-airdrop-to-send-items-iphcd8b9f0af/ios).
2. **Apple's requirement is review evidence, not a marketing App Preview.** This submission's message requests physical-device/latest-OS footage beginning with launch, ordinary use, registration/login/deletion, and applicable UGC/paid flows. It specifies no running time, resolution, bitrate, codec, file-size ceiling, or uninterrupted single-clip condition. Public App Preview specifications separately impose **15–30 seconds and 500 MB**, for the product-page marketing asset. Those numbers must not be presented as review-evidence limits. [Actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [App Preview specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications/).
3. **Two clearly labeled clips are a recommendation, not an Apple acceptance guarantee.** Neither this request nor Apple's public review-reply documentation states that all flows must use one account or be one continuous take. The existing guide's deletion-first/fresh-registration-second order preserves the verifier's exact protected set. Both clips should begin with launch, identify their separate account purposes, and retain honest pauses/verification boundaries. Acceptance of that package is unknown until Apple reviews it. [Actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [Apple reply documentation](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/), [current guide](/Users/shan2new/Projects/previously/docs/release/2026-10-07/physical-device-recording-guide.md), [verifier guard](/Users/shan2new/Projects/previously/docs/qa/2026-10-06/native-live/live-account-erasure-verification.md).
4. **The latest public iOS listed today is 27.0.1, released 28 September 2026.** Capture the owner's model/installed version/update status and the selected TestFlight build as provenance, excluding identifiers. Do not equate the build's SDK version or a simulator runtime with the phone's OS. Recheck the release list and phone when filming because this value changes. Device/build proof is our supporting-evidence recommendation; the physical/latest-OS requirement itself is explicit in Apple's message. [Apple release list](https://support.apple.com/en-us/100100), [actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a).
5. **Review Notes permit 4,000 bytes.** Apple's Notes documentation says bytes; its review-reply screenshot shows a **4,000-character** indicator. Validate UTF-8 byte length for Notes separately from the reply's character count, especially with curly quotes, em dashes or non-ASCII text. [Platform version information → App Review information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/), [Reply to App Review](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/).

## Recommendation

Keep the current two-clip QA order. First, film launch → ordinary login → the one-title/one-episode state → ordinary navigation → guarded deletion → signed-out relaunch, using the existing disposable target. Capture its ready baseline before final deletion and require its qualified post-check before introducing another user. Then film a separate launch → fresh ordinary registration → first-run setup → tracking → sign out/in and restoration. Label the accounts and verification gap truthfully in an index; do not concatenate the clips and imply uninterrupted footage. This sequence is our recommendation based on the verifier's current constraints and the required feature coverage, not an Apple-mandated sequence. [Current recording guide](/Users/shan2new/Projects/previously/docs/release/2026-10-07/physical-device-recording-guide.md), [verifier instructions](/Users/shan2new/Projects/previously/docs/qa/2026-10-06/native-live/live-account-erasure-verification.md), [actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a).

Use native iPhone capture and AirDrop as the default; wired QuickTime or selective USB Photos import are fallbacks. Preserve private originals, inspect playback, and create an explicitly labeled sanitized copy only if a password/code/personal notification appears. Narration, filename conventions and secret masking are evidence-handling choices, not additional Apple rules. If the original upload is accepted, unnecessary resizing/re-encoding adds no documented benefit. If upload rejects size, inspect its exact limit, export a readable H.264 copy with QuickTime and retain the original; if it rejects the container, verify the actual supported type before selecting another existing tool. Do not apply marketing preview limits or buy a recorder/cloud plan. [Apple native recording](https://support.apple.com/en-us/102653), [AirDrop](https://support.apple.com/guide/iphone/use-airdrop-to-send-items-iphcd8b9f0af/ios), [QuickTime capture](https://support.apple.com/guide/quicktime-player/record-a-movie-qtp356b55534/mac), [QuickTime export](https://support.apple.com/guide/quicktime-player/export-movies-qtp20e395859/mac), [Apple reply help](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/).

Provide two recordings plus a short index listing model, installed OS, TestFlight version/build, recording date, each clip's flow and actual timestamps. Include applicable-flow explanations and the six requested factual answers in both the reply and Notes; keep the permanent reviewer credential available in its existing dedicated fields. No promotional movie, generated device frame, simulator footage, artificial tap sequence or staged successful deletion can substitute for the requested physical capture. The physical-device requirement is explicit; index/packaging choices are recommendations. [Actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [App Review information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/).

## Unknowns and source scrutiny

- **Attachment maximum and allowed video formats:** no credible published review-specific values found after four search batches covering review reply, version attachments, file size, MP4 and 20/25/100/500 MB claims. Marketing-preview rules do not fill this gap. Exact UI acceptance and successful processing need verification with the actual artifact. [Reply help](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/), [attachment API](https://developer.apple.com/documentation/appstoreconnectapi/app-store-review-attachments), [distinct preview rules](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications/).
- **Two-clip acceptance, masking acceptance and review speed:** no official guarantee found in the cited request/help. Do not claim that an evidence package guarantees approval, or invent a review turnaround statistic. [Actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [reply help](https://developer.apple.com/help/app-store-connect/manage-submissions-to-app-review/reply-to-app-review-messages/).
- **Physical provenance:** a screen recording alone does not independently prove model/build/latest installed OS. The owner's sanitized phone/TestFlight evidence and truthful recording declaration are the proposed supporting proof; they are not completed results. [Actual request](https://appstoreconnect.apple.com/apps/6818452741/distribution/reviewsubmissions/details/581db571-26c5-4b46-9ead-f7e73a3c940a), [guide](/Users/shan2new/Projects/previously/docs/release/2026-10-07/physical-device-recording-guide.md).
